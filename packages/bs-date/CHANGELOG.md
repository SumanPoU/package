# Changelog

All notable changes to `@itzsa/bs-date` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.1] - 2026-07-31

### Added
- Extended Bikram Sambat calendar coverage **1970–2100**
- Nepali live-clock helpers used by datepicker docs

### Changed
- Keywords / npm metadata for discoverability

## [0.1.0] - 2026-06

### Added
- Headless BS convert, arithmetic, format, holidays
- Pluggable calendar engines
