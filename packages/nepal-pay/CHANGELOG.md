# Changelog

All notable changes to `@itzsa/nepal-pay` are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2026-07-31

First public release.

### Added
- Unified TypeScript SDK for **eSewa ePay v2** and **Khalti KPG-2**
- **ConnectIPS** gateway support with playground/docs flows
- Mandatory server-side verification helpers
- Idempotent confirm patterns for fulfill callbacks
